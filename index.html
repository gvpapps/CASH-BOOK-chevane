💡 Google Firebase मोफत कसे सुरू करावे? (४ सोप्या पायऱ्या)

  1. Google वर Firebase Console उघडा आणि Create Project करा (किंवा जुन्या MDM प्रोजेक्टचीच URL वापरा).
  2. डाव्या बाजूला Build > Realtime Database वर क्लिक करून Create Database करा.
  3. डेटाबेसच्या Rules टॅबमध्ये जाऊन खालीलप्रमाणे रूल्स बदलून Publish करा: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  4. डेटाबेसच्या वर दिसणारी URL (उदा. https://your-app-default-rtdb.firebaseio.com/) कॉपी करून वरील बॉक्समध्ये पेस्ट करा आणि "💾 सेव्ह करा व सुरू करा" दाबा!
